นโยบายความเป็นส่วนตัวและการคุ้มครองข้อมูลส่วนบุคคล

(Privacy Policy & Cookie Policy) • อัปเดตล่าสุด: {{ today|date:"j F Y" }}

บริษัท ทรัสต์ แล็บ จำกัด (TRUST LAB THAILAND) (“บริษัทฯ” หรือ “เรา”) ตระหนักและให้ความสำคัญอย่างยิ่งต่อการคุ้มครองข้อมูลส่วนบุคคลของท่าน เพื่อให้ท่านมั่นใจได้ว่าข้อมูลส่วนบุคคลของท่านจะได้รับความคุ้มครองตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA)

{% icon 'eye' 'i-5 text-amber4' %}1. ข้อมูลส่วนบุคคลที่เราเก็บรวบรวม

  • ข้อมูลติดต่อส่วนบุคคล: ชื่อ-นามสกุล, หมายเลขโทรศัพท์, อีเมล, LINE ID
  • ข้อมูลการจองและธุรกรรม: ประวัติการเข้ารับบริการตรวจสินค้า, รายละเอียดสินค้าแบรนด์เนม, รูปถ่ายสินค้า, ใบเสร็จการชำระเงิน, เลขประจำตัวผู้เสียภาษี (กรณีขอใบกำกับภาษี)
  • ข้อมูลการจัดส่ง: ชื่อและที่อยู่สำหรับการจัดส่งสินค้าคืน
  • ข้อมูลทางเทคนิคและคุกกี้: IP Address, ชนิดของเบราว์เซอร์, บันทึกการเข้าชมเว็บไซต์ (Log Data)

{% icon 'file-text' 'i-5 text-amber4' %}2. วัตถุประสงค์ในการเก็บรวบรวมและใช้ข้อมูล

  • {% icon 'circle-check-big' 'i-5 text-amber4 mt-1' %}เพื่อให้บริการตรวจสอบความแท้ของสินค้าแบรนด์เนม และออกใบรับรอง Certificate (E-Certificate / Physical Card)
  • {% icon 'circle-check-big' 'i-5 text-amber4 mt-1' %}เพื่อยืนยันตัวตนและการติดต่อแจ้งผลการตรวจวิเคราะห์
  • {% icon 'circle-check-big' 'i-5 text-amber4 mt-1' %}เพื่อบริหารจัดการสิทธิประโยชน์สมาชิก (Membership Tier: Silver, Gold, Platinum, Partner)
  • {% icon 'circle-check-big' 'i-5 text-amber4 mt-1' %}เพื่อปฏิบัติตามกฎหมายที่เกี่ยวข้องและระเบียบทางบัญชีและภาษีอากร

{% icon 'lock' 'i-5 text-amber4' %}3. การใช้งานคุกกี้ (Cookies Policy)

เว็บไซต์นี้มีการใช้งานคุกกี้เพื่อจดจำการตั้งค่าการใช้งาน เพิ่มประสิทธิภาพในการเข้าชม และรวบรวมข้อมูลสถิติ ท่านสามารถเลือกตั้งค่าการยอมรับหรือปฏิเสธคุกกี้ที่ไม่จำเป็นได้ตลอดเวลาผ่านแถบการตั้งค่าคุกกี้บนเว็บไซต์
